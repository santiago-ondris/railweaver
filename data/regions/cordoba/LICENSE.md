# Licencia del dataset ferroviario de Córdoba

Los archivos `tracks.geojson`, `stations.geojson` y `railway.overpass.json` contienen una
base de datos derivada de OpenStreetMap y se distribuyen bajo la Open Database License
([ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)).

**Atribución obligatoria:** © OpenStreetMap contributors.

Esta licencia alcanza al dataset derivado. No modifica la licencia del software de
RailWeaver que procesa o visualiza estos datos.

La fecha, la consulta exacta y la procedencia del extracto se registran en
`railway.source.json`.
