# Specs

El trabajo significativo parte de una spec versionada. Cualquier agente debe poder tomarla y empezar sin explicación oral.

- `active/` — en curso (idealmente una por milestone).
- `backlog/` — definidas pero no empezadas (se crea cuando haya alguna).
- `completed/` — terminadas; se mueven acá al cerrar.

Nombre: `RW-NNN-descripcion-corta.md`.

## Plantilla

```markdown
# RW-NNN — Título

- Status: Backlog | Active | Completed
- Milestone / release objetivo:

## Goal
## Scope
## Non-goals
## Inputs
## Outputs
## Acceptance criteria
## Relevant domain docs
## Relevant architecture
## Tests
## Open questions
```
